Häufige Fragen

Werden meine Daten online gespeichert?

Nein. Alle Daten werden lokal auf deinem Mac gespeichert. Es werden keine Informationen an einen entfernten Server gesendet.

Kann ich meine Bankdaten importieren?

Ja. Der Import von CSV-Dateien wird unterstützt (weitere Formate folgen). Achte darauf, dass deine Datei die erwartete Struktur einhält: Datum, Betrag, Beschreibung usw.

Lassen sich mehrere Konten verwalten?

Ja. Lege beliebig viele Konten an und verfolge sie: Giro, Sparkonto, geschäftlich…

Werden Buchungen automatisch kategorisiert?

Eine halbautomatische Kategorisierung wird angeboten: Die App erkennt häufige Bezeichnungen und schlägt Kategorien vor, die du manuell anpassen kannst.

Gibt es eine Version für Windows oder Linux?

Nein. PegaseUIData wird mit SwiftUI ausschließlich für macOS entwickelt. Eine plattformübergreifende Version ist kurzfristig nicht geplant.

Wie melde ich einen Fehler oder schlage eine Übersetzung vor?

Schreib uns an thierry.hentic@gmail.com mit deiner macOS-Version, den Schritten zum Reproduzieren des Problems und – wenn möglich – einem Screenshot. Jede Hilfe bei Übersetzungen ist willkommen!

Bereit, die Kontrolle zurückzugewinnen?

Lade PegaseUIData herunter und verwalte deine Finanzen in wenigen Minuten. Kompatibel mit macOS 14 (Sonoma) und neuer.
