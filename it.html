Domande frequenti

I miei dati sono archiviati online?

No. Tutti i dati sono salvati localmente sul tuo Mac. Nessuna informazione viene inviata a un server remoto.

Posso importare i miei dati bancari?

Sì. È supportata l'importazione di file CSV (altri formati in arrivo). Assicurati che il file rispetti la struttura prevista: data, importo, descrizione, ecc.

Si possono gestire più conti?

Sì. Crea e monitora tutti i conti che vuoi: corrente, risparmio, professionale…

Le operazioni vengono categorizzate automaticamente?

È offerta una categorizzazione semiautomatica: l'app riconosce le diciture frequenti per suggerire categorie, che puoi modificare manualmente.

Esiste una versione per Windows o Linux?

No. PegaseUIData è sviluppata in SwiftUI solo per macOS. Una versione multipiattaforma non è prevista a breve termine.

Come segnalare un bug o proporre una traduzione?

Scrivici a thierry.hentic@gmail.com indicando la versione di macOS, i passaggi per riprodurre il problema e, se possibile, una schermata. Ogni aiuto con le traduzioni è benvenuto!
